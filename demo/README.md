# Демонстрация

`output/` содержит готовые отчёты по 19 сценариям (JSON, HTML, docx с комментариями Word), справочники из локальных копий. Сценарии 1-15 в режиме правил без модели, пересобрать: `python demo/build_demo.py`; 16-19 с локальной моделью, `python demo/run_llm_cases.py` при поднятом сервере. Для ТЗ из ЕИС исходники в репозиторий не входят (в них контакты сотрудников заказчиков), в отчётах ПД заменены метками `[PERSON_1]`, `[PHONE_1]`, comments.docx для них не создаётся.

Прогон через Docker и API: `sh demo/run_demo.sh` или `powershell -File demo/run_demo.ps1`, результаты в `demo/out/`.
